PLAN DETAILS : INITIATE_PROTOCOL

Initiate Protocol [FREE]

This is the entry-level sandbox mode. It is designed to let you test the Z-OS ecosystem before committing to API usage costs.

> What are 6,500 Tokens?

In AI terms, a "Token" is a piece of data processed by the LLM. Every command you type costs tokens.

6,500 tokens allows for:
• ~1 highly complex "Reasoning" command.
• OR ~3 simple, direct text executions per day.

> Local Browser Automation

The free tier allows Z-OS to securely open new tabs in your local Chrome or Edge browser, type URLs, and execute Google searches without you touching the keyboard.

> Standard Text Execution

Command Z-OS to inject raw text payloads directly into your currently active window automatically.
